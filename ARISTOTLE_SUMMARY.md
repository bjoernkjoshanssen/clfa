# Summary of changes for run b85e1215-12ac-45b9-bb1a-825f640768e8
I proved that lattice #61 is the congruence lattice of a finite algebra, using the Hall–Janko group representation `[D₂₀, J₂]`. I picked `J₂` over `J₂:2` and `U₅(2)` because it is the smallest of the three groups, so the computation is the most manageable. The proof has no `sorry` and the default target builds. Like the earlier `prop:hand` proof, it uses `native_decide`, so it relies on `Lean.ofReduceBool` and `Lean.trustCompiler` as well as the standard axioms.

**Main results** (in `RequestProject/J2/Lattice61.lean`):
- `lattice61_representable : ∃ (X : Type) (_ : Finite X) (ι : Type) (F : ι → X → X), Nonempty (UnaryCon F ≃o L61)`. Here `UnaryCon F` is the lattice of equivalence relations on `X` that are compatible with every operation `F i`, i.e. the congruence lattice of the unary algebra `⟨X; F⟩`. The finite algebra used is the coset set `J2 ⧸ D20`, with one operation `x ↦ g•x` for each `g ∈ J2`.
- `con_J2_mod_D20`: the congruence lattice of this coset algebra is isomorphic to `L61`.
- `interval_D20_J2 : Nonempty (Set.Icc D20 J2 ≃o L61)`, stated in the subgroup lattice of `Equiv.Perm (Fin 100)`. `J2` is generated by the ATLAS standard generators of the Hall–Janko group on 100 points (renumbered 0–99). `D20` is generated by two explicit permutations.

**Definitions.** `L61` has elements `0,a,b,c,d,e,f,1` with `a<e,f`, `b<d,e`, `c<d`. I took this from the caption of Figure 2 because `lat8.txt` was not in the project, so please check it matches line 61 there. The general fact that the congruences of `Γ ⧸ K` correspond to the interval `[K, Γ]` is proved for any group in `RequestProject/J2/Congruence.lean` (`conIso`).

**How it's proved.** As with `prop:hand`, this is a machine-checked computation, not a formal version of an argument by hand.
1. I computed the data with GAP (`scripts/gen.g`, output in `scripts/data.txt`): the subgroup `D₂₀`, 1578 representatives of its double cosets in `J₂`, and words in the generators. Lean treats this data only as hints and re-checks all of it.
2. Lean checks that the union of the 1578 double cosets is closed under multiplication by the generators of `J2`, so it contains all of `J2`.
3. For each representative `r`, explicit words identify the subgroup generated by `D20` and `r` with one of eight explicit subgroups. These eight have orders 20, 100, 120, 320, 1920, 600, 300 and the whole group, matching the orders in Figure 2.
4. Lean also checks that these eight subgroups are ordered like `L61` and closed under joins, so every intermediate subgroup is one of them.

**Not proved:** that `J2` has order 604800, the index 30 240, or that `J2` is the Hall–Janko group. The representability result doesn't need any of these; the theorems are about the explicit permutation group.

**Build setup.** Checking the certificate in interpreted Lean was far too slow, so I put the computational code in a small library `J2Fast` (`J2Fast.lean`, `J2Fast/`) that uses only the Lean core library. The `lakefile.toml` compiles it to native code (`precompileModules`), and the checks now take about a minute. The earlier `prop:hand` files are unchanged and still build.

# Summary of changes for run 8bfcea80-4c9f-4d1f-a84b-f9e28c534d4d
I proved Proposition `prop:hand` from `L7_note.tex` in Lean. The proof has no `sorry` and builds with the default target. It does use `native_decide`, so it relies on the compiler-trust axioms (`Lean.ofReduceBool` and `Lean.trustCompiler`) as well as the standard ones (`propext`, `Classical.choice`, `Quot.sound`).

**Statement** (`PSL264.prop_hand` in `RequestProject/PSL264/PropHand.lean`):
```lean
theorem prop_hand (H : Subgroup (Matrix.ProjectiveSpecialLinearGroup (Fin 2) (GaloisField 2 6)))
    (hH : Nonempty (H ≃* Equiv.Perm (Fin 3))) : Nonempty (Set.Icc H ⊤ ≃o L7)
```
This covers any subgroup `H ≅ S₃` of Mathlib's `PSL(2, 𝔽₆₄)`. `L7` (in `L7.lean`) is the seven-element lattice from the note, with the note's covering relations.

**How it's proved.** This is a machine-checked computation, not a formal version of the note's argument via Dickson's theorem.
1. **A computable model** (`GF64.lean`, `SL2.lean`). I built 𝔽₆₄ as bit-vectors modulo x⁶+x+1 and proved the field axioms by exhaustive checking. `SL(2,64)` is then a concrete group of 2×2 matrices. I proved it is isomorphic to Mathlib's `PSL(2, GaloisField 2 6)`, using uniqueness of finite fields and the fact that the centre of `SL(2, ·)` is trivial in characteristic 2.
2. **All S₃ subgroups are conjugate.** Every element of order 3 is conjugate to a fixed one, using an explicit conjugator checked on every group element. Every involution inverting it is conjugate to a fixed involution while the order-3 element stays fixed. So any `H ≅ S₃` is conjugate to `H₀ = SL(2,2)`.
3. **The overgroups** (`Overgroups.lean`). There are seven explicit subgroups containing `H₀`: `H₀`, D₁₈, D₄₂, A₅, D₁₂₆, `SL(2,8)` and the whole group. The finite ones are computed as lists and checked to be subgroups. For all 262,080 elements `g`, the subgroup generated by `H₀` and `g` is shown to equal one of the seven. The evidence is a table in `Table.lean` with one word per double coset of `H₀` (7,303 entries). I generated the table offline, but it is only a set of hints: Lean re-checks every entry. The seven subgroups are closed under joins, so every overgroup of `H₀` is one of them. Their containments match `L7` exactly: J₁ = D₄₂, J₂ = D₁₈, M₁ = D₁₂₆, M₂ = `SL(2,8)`, K = A₅.

The whole build takes a few minutes, mostly for the computational checks. The Properties table lists the theorem (proved) and the `L7` definition.
